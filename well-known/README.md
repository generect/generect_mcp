# well-known

Files served under `/.well-known/` that are not generated by the server.

- `google-connected-apps.json`: domain verification token for Google's
  Connected Apps platform (Gemini, AI Mode in Search). Download it from
  Google Connected Console (app → MCP endpoint → **Download token**) and commit
  it here unchanged; the server serves it at
  `https://mcp.generect.com/.well-known/google-connected-apps`. Not present
  until the console issues one. `GOOGLE_CONNECTED_APPS_VERIFICATION` in the
  environment overrides the file. See `src/google-verification.ts`.
